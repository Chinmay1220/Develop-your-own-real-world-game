## Fancy Components by Daniel Petho

Part of `text.js` (the rotating words) follows TextRotate from https://github.com/danielpetho/fancy. It keeps the same behaviour: letters rise in from below with a spring, the old word leaves upwards, and one word shows at a time. It uses the Web Animations API instead of React and Motion. MIT License, Copyright (c) Daniel Petho.
